=====================================================
1. TAILSCALE NETWORK SETUP
=====================================================

Each computer logs into Tailscale with their own created account.

Coordinator:
1. Create the Tailscale tailnet.
2. Invite the computers as user by their account email from the Tailscale webpage.
3. Wait for the users to accept and connect.
4. Approve users.

Distributed computer:
1. Install Tailscale:
   https://tailscale.com/download
2. Accept the invitation link from the coordinator.
3. Log in to Tailscale.

Linux:
sudo tailscale up

macOS:
sudo tailscale up

Windows:
Open the Tailscale app and log in.


tailscale ip -4
Example:
100.74.226.3

tailscale netcheck


=====================================================
2. RUNNING THE APP (current GUI-based flow)
=====================================================

There is no manual R/package install step and no CLI workflow anymore —
both roles are Shiny apps started from the Run/ launchers, which install
any missing R packages automatically on first launch.

Site (each hospital computer):
0. First time only: once on the tailnet, open the kit link the coordinator
   sent you, click download, and unzip it.
1. Open Run/Mac, Run/Windows, or Run/Linux and double-click "Start Site".
2. Paste the invite the coordinator sent you, click Join, confirm.
3. Select your CSV data file, click Start Server (port is automatic).
4. Your site registers itself with the coordinator automatically.

Coordinator (the researcher):
1. Double-click "Start Coordinator" in the same Run/ folder.
2. Click "Invite a site" for each site. Send the short link — or, for a
   first-timer with nothing installed, expand "First time?" for one
   message covering Tailscale, the kit, and the invite together. Sites
   appear in the table automatically as they join — no addresses or
   tokens to collect or type by hand.
3. Load an analysis script, then Ping -> Validate -> Run Analysis.

Full details: see README.md ("Getting started").
